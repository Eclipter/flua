# Wallpaper artwork

These original images were generated with the built-in ImageGen tool. They are bundled locally; playback never contacts an image service. Each wallpaper source is 1586 × 992 pixels. The scenes animate mist and birds over Ink Mountains, separate pine sprites over its fixed artwork, windblown sand and dust over Sahara, streamlets along Contour Atlas waterways, and flowing ink pigment over Optical Current. The painted pines in Ink Mountains remain part of the fixed background.

Ink Mountains and Sahara advance at a 2× base rate; Contour Atlas and Optical Current use the original 1× rate. The Speed control multiplies each scene's motion rate.
