# Feature status

Flua is a local wallpaper library for macOS 27+ on Apple Silicon. Playback uses the embedded native provider and continues after Flua exits. The provider uses private APIs and ad-hoc signing. Recorded real-host checks used macOS 27.0.1 (26A434) with one built-in display; other OS versions and physical multi-display behavior remain unverified.

## Validation scope

`make test` covers deterministic model, path, package, native descriptor and GPU preview behavior. `make smoke` covers isolated application workflows, previews, import/export, editor changes and accessibility names; it disables system wallpaper operations. `make wallpaper-test` covers standalone provider rendering, lifecycle, recovery and XPC. Inspector checks cover video and scene Still/Animated transitions, separate surface modes, video time progression and submitted scene frames after resume. Desktop inspection confirmed the Still frames and visible video playback; the scene’s Metal output was black in the desktop capture, so its resumed rendering was checked by submitted frame counts. These checks do not establish real-system playback.

Recorded real-host checks cover scoped media access, catalog refresh, direct Apply, Stop/removal, launch restoration, rendering edits, Lock Screen assignment routing, image/video recovery and explicit reapply after provider termination. Video Animated/Still and aurora Still screen-saver transitions, aurora Animated idle after automatic timeout, and brief aurora Still locking passed with the containing harness exited. A separate one-display check confirmed distinct cosmos Desktop and ember Still Lock Screen content. This does not verify file-media pairs, mixed-provider pairs or multi-display behavior. Detailed observations and their individual limits are in the [provider results](../Sources/WallpaperExtension/README.md#real-host-feasibility-result).

Native fullscreen entry/exit paused and resumed Desktop scene frames with Flua closed on one built-in display on macOS 27.0.1. Physical power transitions were manually verified by the user. The native wallpaper backing surface visibly rendered still and animated fixtures at two Retina scaling modes on the built-in display; the captured layer was behind desktop windows. VoiceOver activated Previous, Next, Stop and Set Wallpapers with a disposable matching-catalog build on one built-in display on macOS 27.0.1. Previous and Next changed the playlist entry, Stop halted native playback, and Set Wallpapers applied the selected wallpaper. Physical multi-display behavior, sleep/wake and HDR remain unverified. Earlier VoiceOver captions also verified library search, filters, tags, favorites, blocked tags and playback-control label discovery. Remaining work is listed in [PLAN.md](PLAN.md); repeatable checks are in [DEVELOPMENT.md](DEVELOPMENT.md).

## Library behavior

Settings opens in the main window from the sidebar, app menu, Command-comma or menu bar menu. It replaces the wallpaper content and inspector; selecting a library section returns to browsing. Display mode is selected in the playback controls, and shuffle is set per playlist in Playlist Options. The inspector uses the same native animation in opposite directions when entering and leaving Settings, respecting Reduce Motion.

The right inspector uses a 24-point top margin and shows the selected wallpaper's title above its preview, followed by editable details and playback settings. Tags appear only in the editable text field, without duplicate tag buttons.

The bottom panel centers the display-mode and playback controls without a status line. Previous and Next are gray and disabled unless the selected surface on a targeted display has an active playlist; pausing automatic advancement keeps them available. Stop is always enabled. Import confirmations and Undo appear above the wallpaper list.

Global **Add Wallpaper…** accepts multiple files and supported packages without filling the current playlist. File drops use the same importer. Video imports reject external track references, so accepted movies play from Flua’s own copy after the source is moved. Symbolic links to media files are imported as independent copies, so moving or removing the original does not break the imported wallpaper. Successful imports reset browsing filters, reveal the batch and offer Undo. Clear filters appears when filters or search are active, or sorting differs from Name. It clears filters and search and resets sorting to Name. Undo removes entries from the library and playlists while retaining source and copied media. Added wallpapers with blocked tags remain temporarily visible until the import confirmation is dismissed. Playlist **Add Wallpapers…** offers existing items and **Add Files…**.

Category accepts user text; the menu includes existing visible categories and Abstract, Nature, Space, Urban and Unknown. Color is derived from the average sRGB thumbnail color and can be edited; it is an approximate classification, not a dominant-color analysis. Motion intensity is Low, Medium, High or Unknown and is curated or explicitly edited/imported rather than inferred from video movement. All missing classifications have an Unknown choice. The inspector shows the name, tags, category, color and motion fields at all times; name, tags and category text edits save when you press Return.

Resolution buckets require both the long and short pixel edges to meet 1280×720, 1920×1080, 2560×1440 or 3840×2160; the highest satisfied threshold wins, independent of orientation. Smaller media is Below 720p. Aspect ratio uses width/height: Portrait below 0.95, Square from 0.95 through 1.05, Standard above 1.05 and below 2, and Ultrawide at 2 or above. Media without measurable dimensions uses Unknown.

The inspector shows measured, orientation-corrected dimensions, copied-file size, source duration, trimmed duration when different, and date added. Images have no playback duration; procedural scenes have no source dimensions, file size or source duration. Facts for legacy imports are filled in asynchronously; historical date added remains Unknown. Missing or unreadable media leaves unavailable facts unknown. Packages carry category/color/motion classifications; receiving libraries measure the exported media and record their own import date.
