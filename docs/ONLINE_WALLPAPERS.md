Ranged previews are built after an explicit Preview action from the source’s self-contained video data. Flua validates each HTTP byte range, uses AVFoundation sample references to identify all required bytes in the preview time range, disallows external asset references, and exports only the video track to a temporary silent H.264 excerpt. The source request is capped at 12 MB and the excerpt at two seconds. The excerpt is removed when the preview closes. Full downloads are stored unchanged. Package export carries the source attribution and appends a notice that Flua re-encoded the video and removed audio.

An earlier `curl` request for ISO Republic's advertised MP4 returned HTTP 403, while an ephemeral Foundation `URLSession` GET of the same public URL returned HTTP 200 and the native video file. The cause of the client difference is unknown. Cute Stock Footage's current public item page returned HTTP 200 to an ephemeral Foundation `URLSession` request and exposed its explicit Download Video link. An earlier signed Vimeo URL returned HTTP 410 after it expired; Flua now resolves a fresh link on each explicit preview or download. Neither source requires stored cookies or an account in the verified flow.

Cleared native MP4 and MOV files without a smaller rendition use the same bounded excerpt path.

Provider adapters use each publisher’s live search and pagination contract: Dareful HTML pages/search, ISO Republic’s paged WordPress video collection, Cute Stock Footage’s paginated public posts and video search, NASA SVS’s `/api/search/` and page API, and the full linked VideoObject archives for both National Park Service collections. Search results are checked for reuse metadata and supported delivery formats; individual unsupported records remain visible with a reason.
